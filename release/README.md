# 证券从业模拟刷题工具

这是一个依据中国证券业协会公开大纲制作的个人离线学习工具，不是官方题库。题库由个人持有的历年试题整理资料迁移而来，答案按原资料保存，不宣称官方答案或押题命中。

建议先阅读 [考试说明与资料来源](./exam-guide-and-sources.md)、[金融基础教材本地全文](./docs/base-knowledge.html)、[法规教材本地全文](./docs/law-regulations.html)、[开放教材引用与许可](./docs/open-textbook-sources.md) 和 [学习计划](./study-plan.md)。

## 使用方式

1. 使用桌面版 Chrome 打开 `index.html`。
2. 第一次使用时选择“新建学习档案”，创建 `securities-study-profile.sqlite`。
3. Chrome 授权后，答题、收藏、笔记和模考记录会自动写入该文件。
4. 换电脑时，带走这个 SQLite 文件，在另一台电脑中选择“打开学习档案”。

如果浏览器或公司策略不允许网页直接写文件，可使用“导出档案”和“导入档案”。

“知识讲义”会在当前浏览器中自动记录最后看到的知识点或官方大纲标题，同时保存讲义模式、科目和大纲来源。下次从同一地址打开工具时会直接恢复到该节点；若有未完成模考，则优先显示续考入口。阅读位置属于浏览器本地状态，不写入题库，也不会随 SQLite 学习档案迁移到另一台设备。

## 本机 Codex 学习助教

页面最右侧带有可收起的 AI 学习助教。普通双击 `index.html` 时，题库和学习档案仍可完全离线使用；如果要在页面内与本机 Codex 对话，请在项目目录运行：

```bash
pnpm dev
```

然后打开终端显示的 `http://127.0.0.1:43117`。本地服务会自动启动 `codex app-server`，复用 Codex CLI 当前的登录状态，并把当前题目或页面作为可选上下文。首次使用前应确保终端执行 `codex login status` 能显示已登录。

- 服务只监听 `127.0.0.1`，不会开放到局域网。
- Codex 线程使用只读沙箱和“从不批准”策略，不能通过聊天面板修改题库文件。
- 网页不保存或接触 OpenAI API Key；认证由本机 Codex CLI 管理。
- 助教回复在浏览器内安全渲染 Markdown，支持标题、列表、引用、表格、链接、代码块和 LaTeX 数学公式（由本地 KaTeX 排版）；原始 HTML 不会执行，也不依赖 CDN。
- 助教默认按 Codex 的 `web_search = "live"` 模式运行：普通概念和题目解析优先使用本地资料；涉及最新公告、上市状态、现行规则或考试安排时，必须先进行只读联网核验再回答，联网回答应列出关键来源 URL 和访问日期。
- 联网搜索与沙箱命令联网分开控制：聊天仍使用只读沙箱且关闭命令的出站网络，并在助教进程中关闭已配置的 MCP/应用连接和多代理能力；助教只能调用内置 web search。若当前模型供应商不支持 standalone web search，状态栏会明确提示，回答会说明无法联网并降级到本地资料。
- 回复到达时仅在你已经位于消息底部附近才自动跟随；如果你上滑查看历史消息，新的流式内容不会强制把滚动条拉回底部。
- 回答生成中，发送按钮会变为“停止”；点击后会保留已生成内容，并向本机 Codex 发送中断请求。
- 对话会使用 Codex 额度并需要联网；断开聊天服务不会影响离线刷题和学习记录。
- 如需临时关闭联网搜索，可启动服务前设置 `SECURITIES_CODEX_WEB_SEARCH=disabled pnpm dev`；也支持 `cached` 和 `indexed` 模式。默认 `live` 需要当前 Codex 版本和模型供应商支持该能力。
- 当前使用的 `zycrafts` provider 已在 2026-08-30 实测可调用 Codex standalone web search，但其本机配置没有声明能力，因此启动脚本会仅在本次助教进程中补充该声明，不会修改 `~/.codex/config.toml`。如果换用另一个已确认兼容的自定义 provider，可用 `SECURITIES_CODEX_WEB_SEARCH_PROVIDER=供应商ID pnpm dev`；设为空字符串可取消项目级声明。
- 如果状态栏仍提示“当前模型供应商不支持联网搜索”，说明实际启用的是另一个未声明兼容性的 provider；应先依据该供应商文档确认支持情况，再使用上述环境变量，避免把不支持搜索的接口误标为可用。
- OpenAI 官方目前将 app-server 的 WebSocket 传输标为实验能力；本项目使用更稳定的本机 stdio 连接，再通过同源 HTTP 流转给页面。
- 点击聊天区的“＋”会开始一段新对话；最近的界面消息和线程编号只保存在当前浏览器本地。

## 重要提醒

- 换电脑前请确认页面显示“已保存”。
- 不要在两台电脑上同时编辑同一份档案。
- 不要让正在使用的 SQLite 文件由网盘实时同步。
- 本项目只供个人、非商业学习使用。

## 内容基线

- 《证券行业专业人员一般业务水平评价测试大纲（2025）》
- 《证券行业专业人员水平评价测试纪法知识大纲（2026）》
- 《金融市场基础知识》（证券行业专业人员一般业务水平评价测试统编教材 2025）568 页本地识别文本
- 《证券市场基本法律法规》（2020 商业备考教材）274 页本地识别文本，仅作历史辅助；当前 53/130 个法规科知识单元附有可比摘录，不作为现行答案依据
- 2026 新大纲三色笔记：《金融市场基础知识》87 页、《证券市场基本法律法规》98 页本地识别文本，用 `scripts/import-notes.py` 从个人资料包生成
- 题库内容基线和核验截止日期显示在应用侧栏。
- 题库只保留从历年试题整理资料迁移的 2357 道题（去重后，金融 1366、法规 991），其中 2336 道进入练习与模考，其余标记为待核验。每道题都绑定到具体复习资料页码：全部题都有 2026 新大纲三色笔记出处，金融题额外绑定 2025 统编教材页，法规题在 2020 教材有可比内容时同时给出历史教材页，答完题可在解析区直接打开对应页核对原文。每科模考抽取 120 题（40 单选、40 多选、30 判断、10 综合），并为每道题保留来源、年份和页码。资料按“中国现行法律/中国官方资料、国际标准、通用开放教材”分级展示，后两类不冒充中国考试官方答案。
- `data/coverage-report.json` 提供按大纲细项、章节和知识组的自动近似覆盖矩阵；其中“部分关联/未映射”是扩题线索，不等于协会或专家逐条确认，也不代表真实考试命中率。

“知识讲义”页面默认按科目和章节展示知识单元，包括核心结论、解释、正确说法和明确标错的干扰项；第二章中国金融体系等重点范围另含分层精讲、记忆钩子和考试提示。每个知识单元还会绑定 2026 新大纲三色笔记的具体页码，可直接打开原文核对，页内摘录可展开查看。协会统编教材用金色标识，中国法规/官方资料用绿色标识，国际标准用紫色标识，通用开放教材用蓝色标识，2020 法规商业教材用橙红色历史标识。教材摘录可直接打开对应本地页；扫描版识别文字可能存在同形字、标点或表格误差，仍应以原书为准。2020 教材不是协会统编教材，涉及法条、期限、比例、处罚和业务规则时必须以最新官方文本为准。大纲位置被弱化为可忽略的范围核对信息。“背诵卡”会让你先主动回忆，再按“还不会 / 模糊 / 已掌握”记录复习间隔。

历年真题资料迁移在 `content/imported-exams.json` 中维护，原始文件及其 SHA-256、年份、题号和 PDF 页码保存在 `docs/exam-sources/`。题目会自动关联现有知识点和教材页用于复习定位；标记为待核验的题目不会进入默认练习或模考。模考使用两科通用业务卷结构（40 单选、40 多选、30 判断、10 综合，总分 100），综合题和单选题按样卷分值计分。

“综合案例专项”按完整材料出题，同一段材料下的全部小问连续出现（资料中的材料题每段 1-6 问不等）。该案例配比是本项目为强化迁移能力设置的训练方案，不代表协会公布的真实题型占比。

## 开发说明

运行工具不需要 Node.js。只有重新生成题库、更新大纲或执行内容校验时才需要开发环境：

```bash
npm install
npm test
```

界面样式使用 Tailwind CSS v4 的本地构建，不使用 CDN。`styles.input.css` 是主题与组件样式源码，`styles.css` 是生成产物；修改样式后运行：

```bash
npm run build:styles
```

开发时可用 `npm run watch:styles` 持续编译。`npm run build:release` 和 `npm test` 会自动先生成最新 Tailwind 样式。

大纲提取脚本使用 macOS 的 PDFKit/Swift 和 `textutil`；已经生成的发布版不受此限制。
