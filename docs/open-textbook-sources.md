# 通用开放教材引用与许可（非中国考试官方教材）

本页两本 Saylor 教材均为 2012 年美国开放教材，不是中国大陆官方教材，不是中国证券业协会统编教材，也不代表中国现行金融规则。项目只把它们用于辅助理解通用金融原理，不把它们计作中国考试答案依据。

中国证券业协会官网当前列出的考试用书是《证券行业专业人员一般业务水平评价测试统编教材（2025）》，其中包括《金融市场基础知识》，由中国证券业协会编、中国财政经济出版社出版。项目已另行收录该书的本地识别文本，并用“协会统编教材 · 请核对原书”标签与本页开放教材明确区分。官方订购信息：https://www.sac.net.cn/fwdt/ksfw/jcdg/202512/t20251231_70825.html

本项目只摘录理解知识点所需的开放教材短段落，并保存章节、段落 ID 和原始链接。卡片中的中文内容是项目根据英文原文制作的短译，不是教材官方中文版。

## 使用边界

- 开放教材卡片统一标为“通用开放教材 · 非中国考试官方教材”，不与协会统编教材合并计数，也不替代中国考试教材或现行规则。
- 英文教材解释一般金融原理，不代表中国现行发行、上市、交易、监管或考试口径。
- 中国制度性知识优先引用国家法律法规数据库、中国政府网、中国人民银行、证监会体系、证券交易所及其他监管部门材料。
- 若教材原理与中国现行法规或交易规则存在差异，以现行中国法规和官方规则为准。
- 本项目为个人、非商业学习工具；再分发或改编教材摘录时仍须遵守原许可的署名、非商业和相同方式共享要求。
